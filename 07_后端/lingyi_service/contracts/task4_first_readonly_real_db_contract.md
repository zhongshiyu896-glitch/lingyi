# Task4 第一批只读接口真实化字段契约

范围：本契约只覆盖“第一批只读接口真实化”的字段回归。当前架构已重锚为 FastAPI 自建：库存、财务、权限源均不得依赖 ERPNext 9081；`APP_ENV=production` 必须使用 `LINGYI_PERMISSION_SOURCE=fastapi`。文中保留的 adapter 仅表示存量兼容/外部同步残留分支，不作为生产主数据源。

统一口径：响应信封沿用 `{code,message,data}`，成功 `code="0"`；分页列表沿用 `{items,total,page,page_size}` 且 `page_size<=100`。鉴权沿用 `X-LY-Dev-User`、`X-LY-Dev-Roles`；未登录 401。

| 端点 | 字段契约（以 `app/schemas/*` 为准） | 真实数据来源 | dev/local 缺口说明 |
| --- | --- | --- | --- |
| `GET /api/sales-inventory/customers` | `items.name, items.customer_name, items.disabled, total, page, page_size` (`CustomerItem`) | FastAPI native: `ly_sales_inventory_reference_draft(reference_type='customer')` / master-data 投影；adapter 仅为存量兼容分支 | 本地草稿无外部 ERP company 字段，`company` 仅作本地筛选条件，不出现在 `CustomerItem` |
| `GET /api/sales-inventory/suppliers` | `items.name, items.supplier_name, items.disabled, total, page, page_size` (`SupplierItem`) | FastAPI native: `ly_sales_inventory_reference_draft(reference_type='supplier')` / master-data 投影；adapter 仅为存量兼容分支 | 本地草稿无外部 ERP company 字段，`company` 仅作本地筛选条件，不出现在 `SupplierItem` |
| `GET /api/sales-inventory/warehouses` | `items.name, items.company, items.warehouse_name, items.disabled, total, page, page_size` (`WarehouseItem`) | FastAPI native: 本地仓库/库存流水投影；adapter 仅为存量兼容分支 | 本地草稿无停用事实时 `disabled=false` 为历史只读占位 |

| `GET /api/sales-inventory/sales-orders/{name}` | `name, company, customer, transaction_date, delivery_date, status, docstatus, grand_total, currency, items.name, items.style_master_id, items.item_code, items.item_name, items.color, items.size, items.qty, items.delivered_qty, items.rate, items.amount, items.warehouse, items.delivery_date, items.ys_material_calc_state` (`SalesOrderDetailData`) | FastAPI 原生 `ly_sales_order` + `ly_sales_order_item`；legacy dev/local 回读仍兼容既有销售订单草稿 + outbox payload + draft items | 本地 legacy 草稿 `items.style_master_id/items.delivered_qty` 可为空；不伪造真实交付 |

| `GET /api/bom/` | `items.id, items.bom_no, items.item_code, items.version_no, items.is_default, items.status, items.effective_date, total, page, page_size` (`BomListItem`) | `ly_apparel_bom` | 无 |
